# 回報系統（Google 試算表 + Apps Script）

玩家在遊戲裡按「回報問題」送出的內容，會寫進一個 Google 試算表，也可以寄信通知你。不用另外架伺服器，也不用付費。

## 設定步驟（大約 5 分鐘，只要做一次）

1. 開一個新的 Google 試算表（網址列輸入 `sheets.new`），取名「Under the Hammer 回報」。
2. 上方選單 **擴充功能 → Apps Script**。
3. 把編輯器裡原本的內容全部刪掉，貼上 [`Code.gs`](Code.gs) 的內容，按存檔。
4. 上方函式選單選 **testReport**，按 **執行**。第一次會要求授權：
   - 選你的 Google 帳號。
   - 出現「Google 尚未驗證這個應用程式」時，按 **進階 → 前往（不安全）**，再按 **允許**。這是你自己寫的程式，只會讀寫這份試算表和寄信給你自己。
   - 回到試算表，應該會多一個「回報」工作表，裡面有一筆測試資料，信箱也會收到一封通知信。
5. 右上角 **部署 → 新增部署作業**：
   - 類型選 **網頁應用程式**。
   - 執行身分：**我**。
   - 誰可以存取：**所有人**。
   - 按 **部署**，複製「網頁應用程式」的網址（`https://script.google.com/macros/s/…/exec`）。
6. 把這個網址填進 `index.html` 裡的 `REPORT_URL`（目前使用中的網址已經填好）。

用瀏覽器打開那個網址，看到「Under the Hammer 回報系統正常運作中。」就代表部署成功。

## 之後要改程式

改完 `Code.gs` 之後，要到 **部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選「新版本」→ 部署**，網址不會變。直接按「新增部署作業」會產生新的網址。

## 試算表的欄位

收到時間、類型、內容、聯絡方式、版本、來源（網站或 claude.ai）、遊戲日期、地點、頁面、經費、星級、裝置、螢幕、語言、錯誤紀錄、存檔代碼、處理狀態。

- **存檔代碼**：在遊戲的「設定 → 匯入」貼上，就能看到玩家回報時的進度。
- **處理狀態**：預設是「未處理」，處理完可以自己改。

## 其他設定

- 不想收通知信：把 `Code.gs` 開頭的 `NOTIFY_EMAIL` 改成 `false`。
- 防灌爆：一分鐘最多收 20 筆（`MAX_PER_MINUTE`），遊戲裡每位玩家也要隔 30 秒才能再送一次。
